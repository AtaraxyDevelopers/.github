# Reporting a security concern

Please report suspected vulnerabilities privately to **waleed@ataraxydevelopers.com**. A project's own security policy takes precedence when it lists a dedicated reporting channel.

Include the affected project and version, a short description of the impact, and safe steps to reproduce. Use synthetic records and redact tokens, passwords, and personal information. Do not attach customer databases, private keys, or production logs containing sensitive data.

Avoid opening a public issue with exploit details before maintainers have assessed the report. For ordinary bugs or feature requests, use the project's issue tracker.

This policy describes the reporting channel; it does not promise a response deadline or a bounty.
